# Smart AgriGuide

Smart AgriGuide is a farmer assistance website with a FastAPI backend, crop recommendation model, leaf diagnosis page, weather and irrigation tools, mandi data, and a Gemini-powered assistant.

## Run it on Windows

Use Python 3.11 or 3.12 for the pinned machine-learning packages.

1. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey). Keep it private; enter it only in the backend terminal or your hosting provider's secret settings.
2. In PowerShell, open the project folder and run:

   ```powershell
   cd backend
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   $env:GEMINI_API_KEY = "your-Gemini-key"
   $env:DATA_GOV_IN_API_KEY = "your-data.gov.in-key"
   python -m uvicorn main:app --reload --port 8000
   ```

3. Open [http://127.0.0.1:8000](http://127.0.0.1:8000). The API documentation is at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

The default assistant model is `gemini-3.5-flash-lite` for faster replies. The backend uses lower reasoning effort for routine chats and, on temporary overloads or read timeouts, tries `gemini-3.6-flash` and then `gemini-3.8-flash`. Set `GEMINI_MODEL` to choose another primary model or `GEMINI_FALLBACK_MODELS` to customize the fallback list. Gemini's free tier has usage limits that can change, so check the current limits in Google AI Studio. Google says free-tier API content may be used to improve its products; avoid sending private farmer information through the free tier. Do not put the key in frontend files or commit it to Git.

### Live mandi market prices

The market page can read the Government of India's AGMARKNET daily wholesale price dataset through data.gov.in. It displays the latest available minimum, maximum, and modal price report for the selected state and supported crop, with the report date and market name. This is a daily report, not a tick-by-tick price feed. Get a data.gov.in API key from your account there; the [data.gov.in help page](https://www.data.gov.in/help) explains API access. This key is separate from the Gemini key. Set `DATA_GOV_IN_API_KEY` in the same backend terminal before starting FastAPI, or add it in your hosting provider's private environment-variable/secrets settings. Never place it in frontend files. If it is missing or the official feed is unavailable, the page labels its bundled benchmark as not live instead of presenting it as a current mandi quote. Historical comparisons, alternative buyer rates, MSP references, and the 7-day estimate remain planning benchmarks and should be verified locally.

The assistant can call the crop recommendation model, Open-Meteo weather endpoint, irrigation calculator, AGMARKNET daily mandi feed, local mandi-price CSV snapshot fallback, and market-strategy calculator. For market questions, it asks for a state or union territory instead of guessing the farmer's location. Spoken replies are generated by Gemini TTS in Telugu, Tamil, Hindi, or English. Telugu and Tamil use `gemini-3.8-flash-tts` by default; Hindi and English use `gemini-3.8-flash-lite-tts`. Set `GEMINI_TTS_MODEL` to override these defaults. If the browser blocks playback, press Play on the reply's audio controls. The `/api/v1/health` endpoint reports whether `GEMINI_API_KEY` is configured.

## Run the website and backend on a server

The FastAPI service now serves the frontend and API from the same website address. For a Python hosting service, configure the project so it installs `backend/requirements.txt`, starts from the `backend` folder, and runs:

```text
uvicorn main:app --host 0.0.0.0 --port $PORT
```

Add `GEMINI_API_KEY` and, if you want official daily mandi prices, `DATA_GOV_IN_API_KEY` in the host's private environment-variable or secrets settings. You can also set `GEMINI_MODEL` and `DATABASE_URL` there. Use a persistent database URL for production if chat history and saved records must survive server restarts; without `DATABASE_URL`, the app uses a local SQLite file, which may not persist on some hosting services.

Hosting setup differs by provider, and the project has not been published yet. Choose a provider that supports Python services and persistent storage if you need saved records.

## Project files

- `backend/main.py` — FastAPI routes and tool handlers.
- `backend/agri_agent.py` — Gemini agent and function definitions.
- `backend/database.py` — SQLAlchemy records and database configuration.
- `backend/requirements.txt` — Python dependencies.
- `frontend/` — static website pages and styles.
